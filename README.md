# dsolutions

A manual tracker of my publicly available SaaS products and dev tools, plus small snippets, guides, and tool maps.

This is a static list — items are added and updated by hand, each with a short description, a link to its git repo, and a link to the published/live version (when available).

Original "Business Landing Page" project. Private. Kept with `blp-next` as the same product lineage.

- Repo: https://github.com/pedrovanzo/blp

"BLP Next" — platform for creating and managing custom landing pages for local businesses in Brazil. Private, no public deployment yet.

### basap

"Provider" side of an appointment/scheduling system (pairs with `basap-native` and `paciente`). No live deployment found.

### basap-native

Expo/React Native mobile client for the `basap` appointment system. Private.
